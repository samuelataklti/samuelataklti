## Featured Research Projects

### API Shield Gateway

**[Explore the project](https://github.com/samuelataklti/api-shield-gateway)**

A concurrency-aware HTTP API security gateway developed in Go, integrating LightGBM inference through the Leaves library for real-time multiclass threat detection.

**Technologies:** Go, LightGBM, Leaves, REST APIs, Concurrency, k6

### API Threat Detection ML

**[Explore the project](https://github.com/samuelataklti/api-threat-detection-ml)**

A reproducible machine-learning pipeline for detecting Benign traffic, BOLA, BFLA, and SQL injection attacks using 12 request-level and behavioral features.

**Research results:** 98.81% test accuracy and 97.17% Macro-F1 on the preserved offline test dataset.

**Technologies:** Python, LightGBM, pandas, NumPy, scikit-learn
